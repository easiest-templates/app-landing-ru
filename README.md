# App Landing Page (RU)

Лендинг для мобильного приложения на русском языке. Идеально подходит для презентации приложений-органайзеров, заметочников, планировщиков и productivity инструментов.

## Технологии

- React 18
- Vite 5
- TypeScript
- Tailwind CSS
- Lucide Icons
- React Router

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Структура

```
src/
  pages/
    Index.tsx      # Главная страница лендинга
    NotFound.tsx   # Страница 404
  components/
    ui/
      button.tsx   # Компонент кнопки
  lib/
    utils.ts       # Утилиты (cn для classnames)
```

## Секции лендинга

- Header с навигацией
- Hero секция с CTA
- Логотипы партнеров
- Отзыв клиента
- Брендинг секция
- Email функции
- Footer
